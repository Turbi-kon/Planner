# Лист — ежедневник с памятью лучше моей

Потому что «я думал, у тебя день рождения завтра» — плохой алгоритм поздравления.

**Python + PySide6 + SQLite. Напоминания поверх окон, Telegram и небольшой завод поздравлений.**

## Что умеет этот ответственный листочек

- Хранить записи: добавление, редактирование, поиск и фильтры. Ваши планы наконец получили таблицу, но не стали от этого проще.
- Напоминать отдельным окном поверх остальных. Да, поверх того самого «ещё одного видео».
- Отправлять сообщения в Telegram. Здесь уже настоящий `sendMessage`, а не философская заготовка.
- Повторять дни рождения каждый год и считать возраст: **21 год, 23 года, 25 лет**. Даже 111 лет не сломают склонение.
- На 18-летие сообщать о совершеннолетии. DLC «Взрослая жизнь» устанавливается без нашего участия.
- На юбилей добавлять праздничное настроение. Каждые пять лет начиная с двадцати — маленький торжественный релиз.
- Раз в полгода удалять старые обычные записи. Дни рождения переживают уборку: торт — долгосрочная инвестиция.
- Менять тему: серая по умолчанию, белая для любителей света и тёмная для вечерних коммитов.

## Автопоздравлятор

Отмечаете запись как день рождения, указываете имя, при желании — год рождения, и выбираете стиль: тёплый, шуточный или для программиста.
Дальше работает автомат: **поздравление собирается из списков непосредственно при отправке в Telegram**.
Заранее сочинять текст и хранить его в отдельном поле больше не нужно.


Пять блоков по четыре варианта дают **1024 сочетания на стиль**. Никаких сетевых нейросетей: только локальные списки фраз и здоровое желание поздравить человека без «счастья-здоровья-копировать-вставить».

Обычная запись в Telegram:

```text
Купить молоко
20.10.2026 18:30
Два пакета. И хлеб, раз уж вышел.
```

День рождения в Telegram:

```text
Алексей
20.10.2026 10:00
25 лет — юбилей
От лица отдела хороших коммитов поздравляю тебя с релизом новой версии!

Пусть кофе будет вкусным, коллеги — добрыми, а созвоны — короткими.
```

Если год неизвестен, строка возраста исчезает. Человек сохраняет загадочность, программа — достоинство.
Заметка к дню рождения остаётся напоминанием для вас и в праздничный текст Telegram не добавляется.

**На ПК — обычное напоминание с названием, датой и заметкой. Поздравление туда не подмешивается.**
Пусть бот занимается тостами, а окно на рабочем столе — своей работой.

## Из исходников

Нужен Python 3.10+; сборка проверена на Python 3.12 x64. На Windows можно открыть **run.bat**.


Linux/macOS: используйте `.venv/bin/python`. Windows EXE собирается на Windows; другим ОС нужна собственная сборка.

## Где база

Обычно в `%LOCALAPPDATA%\ListPlanner\ListPlanner\planner.sqlite3`.
SQLite уже входит в Python; отдельный сервер базы данных этому скромному календарю не нужен.

Ключ бота хранится в локальной базе без шифрования. **Не коммитьте базу и ключи**: `.gitignore` уже исключает SQLite, `.env`, окружение и результаты сборки.
Для переноса записей завершите приложение и скопируйте базу на другой ПК. Копирование одного EXE даёт на новом ПК новую пустую базу.

Приложение должно быть запущено, чтобы напоминать. Крестик сворачивает его в трей, если трей доступен; полный выход — через меню значка. Выключенный компьютер пока оставлен в покое.

## Проверка здравого смысла

```powershell
python -m unittest discover -s tests -v
```

Проверяются база и миграции, склонения, юбилеи, переход года, Telegram, повторы и сборка поздравлений.
HTTP в тестах подменён: реальные люди не получают «тест тест тест» ради зелёной галочки.
